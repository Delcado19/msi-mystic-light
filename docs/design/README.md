# Ice workspace - GS-06-R2

The owner-supplied 3840x2160 aurora photo covers the window with proportional
scenery cropping and a dark overlay. The unchanged turbine wordmark is separate,
right aligned and fitted to 360x120 DIP. The document checkerboard remains opaque;
the outer workplane and both panel surfaces reveal the scenery.

The menu bar stays separate. The command row groups workspace, files/history,
Panels/Edit Mode, Preview, and canvas view/alignment. The filename is in the
window title. Fit remains direct; Zoom groups its steps. Dropdowns share one
centered chevron and rounded frame. At 1440 DIP the view selector remains visible;
at 1060 DIP Panels stays reachable and menus retain view/zoom commands.

The left rail separates drawing/navigation from the plus-button effect library.
The library has search and flat category headings. Tool options reserve stable
slots and disable irrelevant fields. Layers and groups have distinct creation
commands; an explicit selected group receives every effect family consistently.
